Lesson 0004: Masked Diffusion — The Practical Starting Point

Estimated time: 30 min · Prerequisites: Lesson 0003 (Core Mechanics)

← Core Mechanics Next → Hands-On Training
tl;dr — Masked diffusion is the simplest practical diffusion algorithm for text. The forward process gradually replaces tokens with a [MASK] token. The reverse process learns to predict the original tokens from the masked sequence. Training uses standard cross-entropy loss (like BERT), and inference starts from all-masked and iteratively unmasks tokens. It's the approach behind LLaDA (8B) and MDLM — and the one you'll train in Lesson 0005.

From Three Families to One

Lesson 0003 introduced the three solution families for discrete diffusion:

  1. Continuous embedding space (Diffusion-LM) — diffuses in ℝd, rounds to tokens
  2. Discrete token transitions (D3PM/SEDD) — diffuses over token categories with transition matrices
  3. Masked diffusion (MDLM/LLaDA) — masks tokens, predicts original

Masked diffusion wins on simplicity. Here's why:

Criterion Continuous Embedding Discrete Transitions Masked Diffusion
Loss function MSE in embedding space + rounding Score entropy / ELBO Cross-entropy (standard)
Forward process Add Gaussian noise Transition matrix (categorical) Replace with [MASK]
Code complexity ~200 lines for training loop ~300 lines (transition matrix math) ~50 lines on top of a transformer
Single GPU feasible? Yes (small scale) Yes (small scale) Yes (up to 1B params)
Production models exist Diffusion-LM (small) SEDD (small) LLaDA 8B, MDLM 1.1B
Bottom line: Masked diffusion is to discrete diffusion what GPT-2 was to AR transformers — not necessarily the best on paper, but the one that actually works well enough to build and ship. Your 8 GB GPU can train a masked diffusion model. Your L40S can run LLaDA 8B.

The Forward Process: Gradual Masking

The forward (corruption) process for masked diffusion is almost trivial:

  1. Start with a clean sequence of tokens
  2. At each timestep t, replace a fraction α(t) of tokens with the special [MASK] token
  3. At t = 0, zero tokens are masked (clean sequence)
  4. At t = T (final timestep), all tokens are masked

The fraction α(t) is called the masking schedule. It determines how many tokens are masked at each step. Unlike Gaussian diffusion (where noise accumulates), masked diffusion is monotonic — once a token is masked, it stays masked through the forward process.

Masking Schedules

The masking schedule dramatically affects training quality. Three common schedules:

Schedule Formula α(t) Behavior Used By
Uniform t / T Linear increase — masks same fraction each step Simple baselines
Cosine 1 − cos(π·t / 2T) Slow start, fast middle, slow end — masks aggressively in middle steps MDLM, LLaDA
γ (gamma) 1 − (1 − 1/T)γ·t Adjustable curvature — γ > 1 masks faster early D3PM absorbing

Interactively compare them below. Notice how cosine scheduling concentrates masking in the middle steps — this forces the model to learn useful predictions across a wide range of corruption levels.

X-axis: diffusion timestep · Y-axis: fraction of tokens masked

Why the schedule matters: If you mask too slowly at the beginning, most training steps see nearly clean data and the model doesn't learn to denoise. If you mask too quickly, most steps are nearly all-masked and the model doesn't learn structure. Cosine schedule balances this — the model sees a wide diversity of corruption levels during training.

The Reverse Process: Iterative Unmasking

The reverse (denoising) process is where the magic happens. Starting from a completely masked sequence, the model iteratively predicts and reveals tokens:

  1. Start with [MASK, MASK, MASK, ..., MASK]
  2. At each step, the model predicts the original token for every position
  3. The model also produces a confidence score for each prediction
  4. Unmask the k highest-confidence positions (where k depends on the schedule)
  5. Repeat until all tokens are revealed or confidence threshold is met

This is fundamentally different from AR generation. Every token prediction is bidirectional — the model sees both left and right context (even if some of that context is still masked). And all predictions happen simultaneously per step.

The trick that makes it work: The model is trained to predict the original token at any masking level. So when the model sees a sequence that is 70% masked, it can still make high-confidence predictions for the 30% visible tokens. Those high-confidence predictions get revealed first, providing more context for the next round.

The Training Objective (It's Just Cross-Entropy)

Here's the practical beauty of masked diffusion — the training objective is cross-entropy loss on the masked positions, exactly like BERT's masked language modeling:

# Masked diffusion training — one batch tokens = [O, rato, roeu, a, roupa, do, rei, de, Roma, .] # shape: [B, L] noise_level = sample_uniform(0, 1) # per sample in batch mask = bernoulli(noise_level) # which tokens to mask masked = where(mask, [MASK], tokens) # replace selected with [MASK] logits = model(masked) # forward pass → [B, L, V] loss = cross_entropy(logits[mask], tokens[mask]) # loss on masked positions only loss.backward()

That's it. No score matching. No ELBO. No transition matrices. Standard cross-entropy, same as any classifier or AR language model. The only difference: you only compute the loss on masked positions.

But isn't this just BERT? Good question. BERT is also trained with masked language modeling — but BERT is not a diffusion model. The difference is the inference procedure:
  • BERT: single forward pass, predicts all masked tokens at once, done.
  • Masked diffusion: iterative — multiple passes, each revealing a subset of tokens, using the newly revealed tokens as context for the next round.
Think of it this way: BERT is one-step denoising. Masked diffusion is multi-step denoising. The training is the same; the inference is fundamentally different.

Full Training and Inference Algorithm

# === TRAINING ===
# θ: model parameters (transformer with bidirectional attention)
# D: dataset of tokenized text sequences

for each batch (x, lengths) in D:
  t = uniform(0, 1) # sample noise level
  α = schedule(t) # fraction to mask (cosine schedule)
  mask = bernoulli(α, shape=x.shape) # which positions to mask
  x_masked = where(mask, [MASK], x) # apply masking
  logits = model(x_masked) # [B, L, V] forward pass
  loss = cross_entropy(logits[mask], x[mask]) # loss on masked positions
  loss.backward() # gradient step

# === INFERENCE (GENERATION) ===
# L: target sequence length (must be known in advance)
# N_steps: number of denoising steps (e.g., 64 for quality, 4 for speed)

x = [MASK] * L # start fully masked
for step = N_steps down to 1:
  α_now = schedule(step / N_steps) # current masking level
  α_next = schedule((step - 1) / N_steps) # next (less masked) level
  logits = model(x) # forward pass
  probs = softmax(logits, dim=-1) # [B, L, V] token probabilities
  confidences = max(probs, dim=-1) # [B, L] how confident per position
  n_unmask = ceil((α_now - α_next) * L) # how many to reveal this step
  masked_positions = where(x == [MASK]) # still-masked indices
  reveal_idx = topk(confidences[masked], n_unmask) # highest-confidence masked positions
  x[reveal_idx] = argmax(probs[reveal_idx]) # set to most likely token

# x now contains the generated sequence

Why Masked Diffusion is Your Practical Starting Point

Three concrete reasons this is the right algorithm to implement first:

1. Minimal Code on Top of a Transformer

If you already have a bidirectional transformer (or can borrow one from Hugging Face), adding masked diffusion is ~50 lines of Python. The forward pass is the same. You just change the loss computation and inference loop.

Your L40S reality check: At 48 GB VRAM, you can train a masked diffusion model with ~350M parameters (similar to GPT-2 medium) on sequences of 512 tokens with batch size 16-32. The cosine masking schedule adds negligible overhead — the cost is dominated by the transformer forward pass, same as any LM.

2. Pre-Trained Models You Can Run Today

LLaDA 8B fits on your L40S with 4-bit quantization. It generates text via masked diffusion natively. You can experiment with its behavior before building your own:

  • LLaDA 8B (ML-GSAI, 2025) — quantized to 4-bit: ~5 GB VRAM. Runs on L40S with room for batch size 4-8.
  • MDLM base (Sahoo et al., 2024) — 360M params. Trains on a single 24 GB GPU. Your 8 GB can handle a smaller version.
  • SMDM (ML-GSAI, 2024) — 1.1B params, shows MDMs match ARMs with 1.4× faster sampling.

3. Clear Upgrade Path

Starting with masked diffusion doesn't lock you in. The skills transfer:

  • → More steps: increase N_steps for quality, decrease for speed
  • → Block-autoregressive: combine with AR for variable-length output (DiffusionGemma approach)
  • → SSM backbone: swap the transformer for Mamba for long-context efficiency (DiffuMamba)
  • → Discrete transitions: graduate to SEDD if you want state-of-the-art perplexity

Training Cost: Masked Diffusion vs AR

A critical table for your hardware planning:

Factor Autoregressive (GPT-2 style) Masked Diffusion
Loss computation Cross-entropy on all positions Cross-entropy on masked positions only
Loss efficiency N tokens contribute to loss per sample ~α·N tokens on average (α is masking fraction)
Forward pass per step Full sequence (causal mask) Full sequence (bidirectional attn)
Forward passes per training step 1 (teacher forcing) 1 (single corruption level per sample)
Total training FLOPs (equal tokens) Baseline ~1× (same transformer size, same tokens)
Training-to-inference mismatch Large (parallel train, serial infer) None (same procedure for both)
Inference FLOPs (2048 tokens) O(L²) with KV-cache O(N_steps × L²) with full attention
Wait — training is the same cost? Yes, per training step. But masked diffusion needs more training steps to converge because each step only provides a learning signal on the masked subset. MDLM (Sahoo et al.) found masked diffusion needs roughly 2× the training tokens of a comparable AR model to match perplexity. For your L40S, this means a 2-day AR training job becomes a 4-day diffusion job. The tradeoff is inference flexibility.

Going Deeper: The MDLM Derivation (Light)

The MDLM paper (Sahoo et al., NeurIPS 2024) provides a clean theoretical justification: masked diffusion can be derived as a mixture of masked language modeling losses over all possible masking levels. The training objective becomes:

L = E_{t ~ U(0,1)} [ λ(t) · E_{mask ~ α(t)} [ CE(logits, target) ] ]

Where λ(t) is a weighting function that prioritizes certain noise levels. The key insight: instead of choosing a single masking level like BERT (typically 15%), MDLM trains on all masking levels simultaneously. The weighting function λ(t) determines which masking levels matter most.

  • Uniform weighting (λ=1): standard approach, treats all noise levels equally
  • ELBO weighting: weights by the variance of the corruption distribution — theoretically optimal
  • λ(t) = 1/(1−α(t)): used by MDLM, gives more weight to lower-noise (easier) steps

For your implementation, start with uniform weighting. It works fine and removes one hyperparameter.
