# Established: fairly-advanced shell user, mission is decluttering

The user self-rates **fairly advanced** with the Linux command line and
filesystem — comfortable with the shell, wants the precise mental model and edge
cases rather than basics. Their concrete goal is **decluttering a cruft-filled
machine**: being able to identify where any installed thing came from (apt, snap,
manual symlink, or `make install`) and remove it cleanly.

Implications for future sessions:
- Do not teach shell fundamentals (navigation, file viewing, redirection).
- Every lesson should end in a runnable real-world action on their own box.
- Pitch at "give me the underlying model + the failure modes," not "here's the
  happy-path command." See [[MISSION.md]].
