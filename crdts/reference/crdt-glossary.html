Reference · CRDTs

CRDT Glossary

The shared vocabulary of the course. Terms are defined once here and used consistently in every lesson. Grows as the course does.

Throughout, the running example is a collaborative whiteboard: shapes on a shared canvas, syncing peer-to-peer and offline. Each definition notes the whiteboard analogue where one exists.

Core concepts

CRDT
Conflict-free Replicated Data Type. A data structure whose merge depends only on the data, never on the order updates arrived in — so replicas converge without a central server or locking. L1
Replica
One independent copy of the shared state — e.g. the whiteboard as it exists on Alice's laptop. Each peer holds a replica and edits it locally. L1
Convergence
The property that replicas which have seen the same updates hold identical state. The goal of every CRDT. L1
Strong Eventual Consistency (SEC)
The formal promise: any two replicas that have received the same set of updates have the same state, regardless of order, duplication, or delay. CRDTs achieve it by construction. L1
Divergence
The failure CRDTs prevent: two replicas permanently disagreeing because they resolved the same concurrent edits differently (e.g. "last to arrive wins" with different arrival orders). L1
Merge
The function that combines two replica states (or a state and an update) into one. For convergence it must obey the three laws below. L1
Concurrent updates
Two updates made without either having seen the other (e.g. both peers offline). These are the updates a CRDT must reconcile deterministically. L1

The three merge laws

Commutative
merge(a, b) = merge(b, a). Order of merging doesn't matter — defeats network reordering. L1
Associative
merge(merge(a, b), c) = merge(a, merge(b, c)). Grouping doesn't matter — defeats batching. L1
Idempotent
merge(a, a) = a. Re-merging the same value is a no-op — defeats duplicate delivery. L1

CRDT types seen so far

LWW-Register
Last-Writer-Wins Register. Holds one value tagged with a timestamp (+ replica id for tiebreak); merge keeps the higher-timestamped write. Whiteboard use: a single shape property such as color or x. Caveat: the losing write is silently discarded. L1

Terms named but not yet taught

Defined properly in later lessons; listed so the forward references make sense.

Semilattice
The algebraic structure formed by a set + a merge obeying the three laws. The reason convergence is guaranteed rather than hoped for. L2 (preview)
State-based (CvRDT) vs operation-based (CmRDT)
Two ways to ship updates: send the whole merged state, or send individual commuting operations. L2 (preview)
Logical clock / Lamport timestamp
A monotonically increasing counter used as ts instead of wall-clock time, so causally-ordered events compare correctly. L2 (preview)
OR-Set, tombstone
Observed-Remove Set and its deletion marker — for the set of shapes on the board, handling delete-vs-concurrent-edit. L3 (preview)
Sequence CRDT (RGA / YATA)
Keeps an ordered list convergent — for z-order of shapes and text inside notes. L5 (preview)
