The pipeline at 50,000 feet

Training a GPT involves exactly five stages. They happen in order, then the last two repeat thousands or millions of times: 

  Raw text
     │
     ▼
  ┌─────────────┐
  │ ① Tokenizer  │  ← splits text into integer IDs
  └──────┬──────┘
         │
         ▼
  ┌──────────────┐
  │ ② Embedding   │  ← maps IDs to high-dimensional vectors
  └──────┬───────┘
         │
         ▼
  ┌──────────────────┐
  │ ③ Transformer    │  ← the "thinking" part — attention + feed-forward
  │    Block(s)      │
  └──────┬───────────┘
         │
         ▼
  ┌──────────────┐
  │ ④ Output Head  │  ← projects back to vocabulary-sized probabilities
  └──────┬───────┘
         │
         ▼
  ┌──────────────────┐
  │ ⑤ Loss & Update │  ← compare prediction to truth, adjust weights
  └──────────────────┘
         │
         └──→ loop back to ③ for next token

Stages ①–② run once (preprocessing). Stages ③–⑤ run for every single token, over and over. The "training loop" is just stages ③→④→⑤ repeated across your whole dataset, many times (epochs).

What each stage does (plain English)

①

Tokenizer — text → integers

A tokenizer takes raw text and splits it into pieces (tokens), then maps each piece to an integer ID. The simplest possible tokenizer is character-level: "cat" → [3, 1, 20]. GPT-2/4 use Byte-Pair Encoding (BPE), which learns the best split points from data. We'll use character-level for lesson 1 because it's trivially understandable.

②

Embedding — integers → vectors

Each token ID (an integer) gets looked up in a table that returns a high-dimensional vector, say 384 numbers. These numbers are learned — they start random and get tuned during training. The embedding layer is the model's way of saying "token #45 is like tokens #12 and #33 in these ways."

③

Transformer Block — the thinking

This is the core. The transformer block considers all tokens in the sequence and lets them "talk to each other" via attention (which tokens are relevant to each other) and then processes each position's result through a feed-forward network (a small neural net applied position-by-position). Stack multiple blocks (12, 24, 96 layers) and you get the model's reasoning depth.

④

Output Head — vectors → token probabilities

The final transformer block's output is still a vector per position. The output head projects that vector back into vocabulary-sized logits — one score per possible next token. Softmax turns those scores into probabilities. The model then samples from that distribution pick the next token.

⑤

Loss & Update — how the model learns

The model predicted a probability distribution over the next token. We know the actual next token (from our training data). The loss (cross-entropy) measures how surprised the model was. High loss = very surprised = bad prediction. We then use backpropagation to compute, for every single weight in the model, "which direction should I nudge this weight to reduce the loss next time?" The optimizer (AdamW) applies those nudges.

That's it. That's the whole learning algorithm. The model improves token by token, batch by batch, epoch by epoch.

"""
Minimal GPT trainer — Lesson 1 of the GPT training series.
Trains a character-level GPT on a tiny slice of Shakespeare.
"""
import os, sys, time, math
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.utils.data import Dataset, DataLoader

# ── Config ────────────────────────────────────────────────
VOCAB_SIZE  = 65       # number of unique characters in our data
EMBED_DIM   = 192      # size of each token's embedding vector
NUM_HEADS   = 6        # number of attention heads
NUM_LAYERS  = 4        # number of transformer blocks
BLOCK_SIZE  = 128      # context length (tokens of history)
BATCH_SIZE  = 64       # sequences per training step
LR          = 3e-4
EPOCHS      = 10
EVAL_INTERVAL = 100    # steps between printing loss
DEVICE      = "cuda" if torch.cuda.is_available() else "cpu"
# ───────────────────────────────────────────────────────────


# ── Data ──────────────────────────────────────────────────
# Download a tiny slice of Shakespeare
DATA_URL = "https://raw.githubusercontent.com/karpathy/char-rnn/master/data/tinyshakespeare/input.txt"
DATA_PATH = "tinyshakespeare.txt"

if not os.path.exists(DATA_PATH):
    print(f"Downloading {DATA_URL}...")
    import urllib.request
    urllib.request.urlretrieve(DATA_URL, DATA_PATH)

with open(DATA_PATH, "r") as f:
    text = f.read()

# Build character-level tokenizer
chars = sorted(list(set(text)))
VOCAB_SIZE = len(chars)
stoi = {ch: i for i, ch in enumerate(chars)}
itos = {i: ch for i, ch in enumerate(chars)}

def encode(s):
    return [stoi[c] for c in s]

def decode(ids):
    return "".join(itos[i] for i in ids)

# Split into train / val
data = torch.tensor(encode(text), dtype=torch.long)
split = int(0.9 * len(data))
train_data, val_data = data[:split], data[split:]

class CharDataset(Dataset):
    def __init__(self, data, block_size):
        self.data = data
        self.block_size = block_size

    def __len__(self):
        return len(self.data) - self.block_size

    def __getitem__(self, idx):
        x = self.data[idx : idx + self.block_size]
        y = self.data[idx + 1 : idx + self.block_size + 1]
        return x, y

train_ds = CharDataset(train_data, BLOCK_SIZE)
val_ds   = CharDataset(val_data, BLOCK_SIZE)
train_loader = DataLoader(train_ds, batch_size=BATCH_SIZE, shuffle=True, drop_last=True)
val_loader   = DataLoader(val_ds,   batch_size=BATCH_SIZE, shuffle=False, drop_last=True)
# ── Model ─────────────────────────────────────────────────

class SelfAttention(nn.Module):
    """One head of scaled dot-product attention."""
    def __init__(self, embed_dim, head_size):
        super().__init__()
        self.key   = nn.Linear(embed_dim, head_size, bias=False)
        self.query = nn.Linear(embed_dim, head_size, bias=False)
        self.value = nn.Linear(embed_dim, head_size, bias=False)

    def forward(self, x):
        B, T, C = x.shape
        k = self.key(x)
        q = self.query(x)
        v = self.value(x)
        attn = q @ k.transpose(-2, -1) * (k.shape[-1] ** -0.5)
        # causal mask — prevents attending to future tokens
        mask = torch.tril(torch.ones(T, T, device=x.device)).view(1, T, T)
        attn = attn.masked_fill(mask == 0, float("-inf"))
        attn = F.softmax(attn, dim=-1)
        return attn @ v

class MultiHeadAttention(nn.Module):
    def __init__(self, embed_dim, num_heads):
        super().__init__()
        head_size = embed_dim // num_heads
        self.heads = nn.ModuleList([SelfAttention(embed_dim, head_size) for _ in range(num_heads)])
        self.proj = nn.Linear(embed_dim, embed_dim)

    def forward(self, x):
        out = torch.cat([h(x) for h in self.heads], dim=-1)
        return self.proj(out)

class FeedForward(nn.Module):
    def __init__(self, embed_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(embed_dim, 4 * embed_dim),
            nn.GELU(),
            nn.Linear(4 * embed_dim, embed_dim),
        )

    def forward(self, x):
        return self.net(x)

class TransformerBlock(nn.Module):
    def __init__(self, embed_dim, num_heads):
        super().__init__()
        self.ln1 = nn.LayerNorm(embed_dim)
        self.attn = MultiHeadAttention(embed_dim, num_heads)
        self.ln2 = nn.LayerNorm(embed_dim)
        self.ff = FeedForward(embed_dim)

    def forward(self, x):
        x = x + self.attn(self.ln1(x))
        x = x + self.ff(self.ln2(x))
        return x

class GPT(nn.Module):
    def __init__(self, vocab_size, embed_dim, num_heads, num_layers, block_size):
        super().__init__()
        self.token_embedding = nn.Embedding(vocab_size, embed_dim)
        self.pos_embedding   = nn.Embedding(block_size, embed_dim)
        self.blocks = nn.ModuleList([
            TransformerBlock(embed_dim, num_heads) for _ in range(num_layers)
        ])
        self.ln_f = nn.LayerNorm(embed_dim)
        self.head = nn.Linear(embed_dim, vocab_size)

    def forward(self, x):
        B, T = x.shape
        tok_emb = self.token_embedding(x)
        pos_emb = self.pos_embedding(torch.arange(T, device=x.device))
        x = tok_emb + pos_emb
        for block in self.blocks:
            x = block(x)
        x = self.ln_f(x)
        return self.head(x)

    @torch.no_grad()
    def generate(self, idx, max_new_tokens=200):
        """Generate text starting from idx (B, T) tensor."""
        for _ in range(max_new_tokens):
            # crop to block size
            idx_cond = idx[:, -BLOCK_SIZE:]
            logits = self(idx_cond)
            logits = logits[:, -1, :]  # last time step only
            probs = F.softmax(logits, dim=-1)
            idx_next = torch.multinomial(probs, num_samples=1)
            idx = torch.cat((idx, idx_next), dim=1)
        return idx


# ── Training ──────────────────────────────────────────────

model = GPT(VOCAB_SIZE, EMBED_DIM, NUM_HEADS, NUM_LAYERS, BLOCK_SIZE).to(DEVICE)
optimizer = torch.optim.AdamW(model.parameters(), lr=LR)

n_params = sum(p.numel() for p in model.parameters())
print(f"Model has {n_params:,} parameters")
print(f"Running on {DEVICE}")
print()

total_steps = 0
for epoch in range(1, EPOCHS + 1):
    model.train()
    epoch_loss = 0.0
    for x, y in train_loader:
        x, y = x.to(DEVICE), y.to(DEVICE)
        logits = model(x)
        loss = F.cross_entropy(logits.view(-1, VOCAB_SIZE), y.view(-1))
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        epoch_loss += loss.item()
        total_steps += 1

        if total_steps % EVAL_INTERVAL == 0:
            model.eval()
            val_loss = 0.0
            with torch.no_grad():
                for vx, vy in val_loader:
                    vx, vy = vx.to(DEVICE), vy.to(DEVICE)
                    vlogits = model(vx)
                    vloss = F.cross_entropy(vlogits.view(-1, VOCAB_SIZE), vy.view(-1))
                    val_loss += vloss.item()
            val_loss /= len(val_loader)
            print(f"step {total_steps:>5d} | train loss {epoch_loss:6.4f} | val loss {val_loss:6.4f}")
            model.train()

    avg_loss = epoch_loss / len(train_loader)
    print(f"─── epoch {epoch}/{EPOCHS} complete | avg train loss {avg_loss:6.4f}")

# ── Generation ────────────────────────────────────────────
print("\n─── Generating ───")
context = torch.zeros((1, 1), dtype=torch.long, device=DEVICE)
output = model.generate(context, max_new_tokens=500)
print(decode(output[0].tolist()))
print("\n─── Done ───")

What to watch for

When you run the script, pay attention to these signals:

SignalWhat it tells you
Loss starts high (~4.0+) The model is predicting randomly — it hasn't learned anything yet.
Loss drops steadily Learning is working. The model is less "surprised" by the next token.
Train loss < val loss Normal and expected. A small gap means healthy generalization.
Large train/val gap Overfitting — the model memorized training data instead of learning patterns.
Generated text starts as garbage Random weights → random output. Normal.
Generated text gets slightly coherent By epoch 5–10 you should see real words and sentence-like structures.
