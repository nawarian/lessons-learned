GPT Training Pipeline Cheat Sheet

The five stages, the key hyperparameters, and how to read training output.

The five stages

① Tokenizer
text → ints → ② Embedding
ints → vectors → ③ Transformer
vectors → vectors → ④ Output Head
vectors → probs → ⑤ Loss & Update
compare + nudge

Stages ③→④→⑤ repeat for every batch. The loop is the training step.

Reading training output

Loss starts high
Good. Random weights give random predictions. Starting loss ≈ ln(VOCAB_SIZE) ≈ 4.17 for 65 tokens.
Loss decreases
The model is learning. Each step nudges weights to reduce surprise.
Train loss < val loss
Expected. The model has seen training data before, not validation data.
Large train/val gap
Overfitting. Model memorized instead of generalized. Solutions: more data, smaller model, regularization.
Loss plateaus
Model capacity exhausted or learning rate too small.
Loss diverges (goes up)
Learning rate too high. Training is unstable.

Common terms

Cross-entropy loss
How surprised the model was by the actual next token. Lower is better.
Backpropagation
The algorithm that computes, for every weight, "which direction should I nudge it to reduce loss?"
AdamW
The optimizer. It decides how much to nudge each weight (accounting for momentum and per-weight scaling).
Epoch
One full pass through the entire training dataset.
Step
One forward + backward + update cycle on one batch.
Perplexity
exp(loss). Intuitive interpretation: "how many equally-likely next tokens does the model see?" Lower = more confident.
Causal mask
A triangular mask that prevents the model from attending to future tokens during training.
